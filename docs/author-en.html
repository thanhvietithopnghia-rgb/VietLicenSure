The person behind the product

Thanh Viet

Author and lead developer of VietLicenSure — a local-first tool for checking, explaining and managing Windows/Office licensing evidence.

TV

Role

Thanh Viet is responsible for product direction, design, implementation, testing, documentation, release integrity and user support. This describes the project role; it is not a claim of professional certification or independent endorsement.

Project GitHubContact

Development principles

Evidence-based

Every conclusion should be traceable to signals, limits and verification steps.

Local-first

Offline by default, no telemetry and no cloud inventory upload.

Fail-closed

No PASS if hashes, signatures, provenance or post-checks fail.

Privacy-respecting

No full keys; identifiers, paths and secrets are redacted from shared reports.

Responsibilities

  • Maintain source, build procedures and the release evidence chain.
  • Test on real Windows systems, including privileges, reboot, LAN and cleanup.
  • Maintain VI/EN documentation and disclose Official Self-Signed limitations.
  • Receive defects, feature feedback and security reports through appropriate channels.

Official channels

Source, releases and change history are published only through the official GitHub repository. Use Private Security Advisory for vulnerabilities and Issues for non-sensitive defects.
