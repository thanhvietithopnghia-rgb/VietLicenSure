First-time user guide

Download correctly, verify first, act safely

You do not need PowerShell expertise to use VietLicenSure. Stop if the checksum, signature, or download source does not match.

1. Download from the official source

Use only the official GitHub Release. Do not run an EXE redistributed through forums, unknown archives, or repackaged downloads.

Download EXE v5.0View release

2. Verify before launch

In the full package, run VERIFY-RELEASE.cmd and require 0 errors. Current EXE SHA-256:

654F60860DB1311F994EF9C611E7F71B3DC3E2B73A07546548F2C8FD898D0AD2

When you only have the EXE, use PowerShell:

Get-FileHash .\VietLicenSure-v5.0.exe -Algorithm SHA256
Get-AuthenticodeSignature .\VietLicenSure-v5.0.exe
Stop if the hash differs, the signature is missing/invalid, the signer does not match, or the timestamp is absent.

3. Run as a standard user

You do not need to launch the entire application with “Run as administrator.” Accept UAC only after selecting a task that genuinely requires elevation.

Stay Offline for local assessment. Enable Online only to intentionally refresh the signed catalog; the app then stops without starting a scan or report. LAN uses a separate switch.

4. Interpret results correctly

StatusMeaning
Activated / LicensedTechnical status within the observed scope; it does not prove legal entitlement.
Needs verificationEvidence is incomplete or requires an invoice, agreement, account, or portal check.
Repair neededAn edition, service, or system file needs attention; prefer official repair tools.
IntegrityCompromisedA file/signature mismatch was found; stop changes and obtain a clean official copy.

5. Use backup and post-action verification

  1. Confirm the product and target.
  2. Use Preview/Dry Run first.
  3. Review planned changes and backup location.
  4. Approve each scoped item; accept UAC only when expected.
  5. Wait for the rescan; completion requires a passing post-check.

6. Open the Central Dashboard

  1. Enable the authorized internal LAN and start the enterprise server.
  2. From the server tab, choose to open the Central Dashboard.
  3. Use the short-lived URL/session generated by the application; do not share its token outside the LAN.
  4. The dashboard is read-only: Online/Stale/Offline, last seen, technical status, License Compliance, and alerts; it does not control endpoints.

Getting support

Include the version, reproduction steps, screenshots, and a redacted support bundle. Never publish a full product key, secrets, or exploit code.
