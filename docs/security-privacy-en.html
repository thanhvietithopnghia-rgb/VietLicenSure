Enterprise policy · version 1.2

Verifiable security, privacy by default

Scope: VietLicenSure v5.0 Desktop, LAN server/Agent, Central Dashboard, License Compliance, and local reports. Effective 2 October 2026.

Release channelOfficial Self-Signed
Default modeOffline
TelemetryNone
DashboardLAN read-only

1. Principles

Local-first

Inventory and reports are processed on the endpoint or an organisation-managed LAN server.

Data minimisation

Only signals needed for technical assessment, reporting and status monitoring are processed.

Transparency

Online mode is opt-in; technical activation remains separate from ownership evidence.

Least privilege

The app starts as a standard user and requests elevation only for an authorised privileged task.

3. Data not intentionally collected or exposed

  • No cloud telemetry or inventory upload by default.
  • No full product keys, passwords, pairing secrets or ClientId in the Dashboard.
  • No full PowerShell or Event Log history in reports.
  • No third-party CDN, remote font or tracker on this documentation site.

4. Storage, access and deletion

Configuration, reports and server data remain on the endpoint or LAN server until an authorised user or administrator removes them. Local secrets use appropriate Windows protection; Dashboard sessions are short-lived, IP-bound and expire after 30 minutes. Each organisation controls its own retention, folder permissions and backup policy.

5. Software and licensing policy

  • Inventory scope: software is identified only on devices within the organisation's managed scope; appearing in inventory does not mean the software is approved or properly entitled.
  • Classification: Freeware, Open Source, Commercial, Subscription, or Unknown is technical guidance; the organisation must still review publisher terms, usage purpose, and restrictions.
  • Installation sources: organisations should define approved repositories or download sources, verify signatures or hashes where available, and restrict installers of unknown origin.
  • Procurement and assignment: License Compliance stores local purchase records, Purchased / Assigned / Installed quantities, licensing metrics, and evidence files supplied by authorised personnel.
  • Use and change: installation, removal, upgrade, or remediation remains subject to organisational authority; VietLicenSure does not automatically remove or block software merely because it is classified as Unknown.
  • Remediation controls: system changes require a preview, confirmation, backup, and post-check; the user can cancel before application.
  • Key protection: full product keys are neither stored nor disclosed; only redacted values or last-five characters are used when identification is required.
  • Assessment: License Advisor provides explanations, risk signals, and recommendations; it does not determine legal infringement or replace legal/audit review.
  • Exceptions and review: Unknown software, quantity overages, or missing evidence should be reviewed by authorised personnel, documented as exceptions, and reassessed periodically.
  • Revocation and retention: when a device or user leaves managed scope, the organisation is responsible for reclaiming or reassigning rights, deleting data no longer needed, and retaining evidence under its internal schedule.
  • Dashboard boundary: evidence files can be added or deleted only through the local administrator workflow; the web Dashboard remains read-only and does not serve evidence files.

6. Security controls

  • Offline by default; Online requires an explicit action.
  • Downloaded catalogs, manifests, provenance and knowledge are checked using signatures, hashes and a pinned signer.
  • The Dashboard and allow-listed API are read-only and cannot control endpoints.
  • System changes use a dry run, confirmation, backup, and post-checks.
  • Reports redact serials, UUIDs, paths and contextual identifiers.

7. Enterprise responsibilities

Organisations should restrict subnets/firewall rules, control authorised administrators, retain entitlement evidence, define report retention and review alerts. Activated/Licensed is a technical signal and does not replace invoices, contracts or licensing portals.

8. Trust status and compliance boundary

Official Self-Signed uses the official pinned signer, hashes/CMS and timestamp; it is not public-CA, EV or Microsoft Store signing. Independent review is currently NotReviewed.

This policy does not constitute ISO 27001, SOC 2 or GDPR certification, a DPA, an SLA, or legal advice. Each enterprise must assess its own legal and internal-control requirements.

9. Security reporting and contact

Submit vulnerabilities privately through GitHub Private Security Advisory. Use GitHub Issues for non-sensitive defects and thanhvietit.hopnghia@gmail.com for general support.
