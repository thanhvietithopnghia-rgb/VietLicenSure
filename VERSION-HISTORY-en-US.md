# Tool Kiem Tra — Version History

## Tool Kiem Tra v5.0 — 2026-08-31

- Technical ProductVersion/FileVersion: `5.0.0.0`
- Release status: `ManagedSigned`

This official upgrade follows v4.9 and focuses on the core improvements:

- Checks hardware configuration and the licence status of Windows, Microsoft Office, and other software.
- Provides Quick, Standard, and Deep scans with prioritized review results.
- Separates Windows, Office, and other-software remediation with preview, Dry Run, backup, confirmation, and post-verification.
- Provides a clear Light/Dark interface, HTML/PDF/JSON/XML reports, and multi-device administration.
- Operates Offline by default and does not automatically send machine data to the Internet.
- Verifies integrity before system-changing actions; Windows may still show SmartScreen or `Unknown publisher` because the current certificate is not a public-CA identity.

`Unverified` does not mean that software is unlicensed.
